# 项目报告与海报

本目录介绍电力系统优化问题校核与修正Skill（Power System Model Audit）为什么检查优化模型、怎样检查，以及已有实验说明了什么。报告于2026-10-25按邓康技术报告的写法修订，配套Skill文档修订版1.1.2。

- [项目报告PDF](report.pdf)：5页，从“能够求解为何还可能写错”这一问题出发，说明检查方法、ReLoop对比、实验设置和具体错误。
- [报告TeX](report.tex)与[文档类](iarticle.cls)：在本目录运行两次`xelatex report.tex`即可编译。
- [A1海报PDF](poster.pdf)与[可编辑PPTX](poster.pptx)：用流程图展示安装使用、知识卡选择、独立计算和修复结果。

阅读时可重点看两个案例：储能代码与检查程序使用同一个错误公式时，为什么仍会相互一致；最小开停机时间多计一期时，为什么当前解看似正常，却会拒绝合法运行方案。这两个问题分别说明了独立计算和完整方案检查的作用。

报告和海报中的对照数据来自v0.15实验。A/B/C最终修复分别通过44/48、44/48、48/48项，C组包括三项追加运行，追加前为45/48。当前文档修改没有改变这些结果，1.1版也尚未开展同样的模型效果对照。作者、课程和学号保留在报告与海报中，便于课程识别。
