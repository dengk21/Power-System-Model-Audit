# Power System Model Audit v1.1.1

本次主要修改文档表达，使读者能够先理解要解决的问题，再理解程序怎样检查。计算方法和实验结果沿用1.1版。

## 修改内容

报告按照“问题—方法—结果—解释”的顺序重新整理。例如，先说明求解器为什么无法替代物理检查，再用储能效率和最小开停机时间两个案例说明独立计算的作用。原有公式、实验设置、数值、引用来源及C组追加运行的说明保留。

三个仓库README改为先介绍使用目的，再给出环境、命令、预期结果和目录。将“活动代码”写为“实际运行的代码”，“轨迹成员检验”解释为“检查模型是否允许参考运行方案”，“fixture”解释为“预设数值例子”。详细技术名称和命令保留在需要使用的位置。

简报和详细报告模板也采用同样写法：先说明问题是什么、在哪里、应该怎样处理，再列公式和计算依据。错误分类、状态字段和判断规则保持原样。
