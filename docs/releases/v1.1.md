# Power System Model Audit v1.1

本版完善了知识卡驱动的专项检查、项目关系覆盖与运行记录采集，并附上最新项目报告和海报。

## 主要变化

- 插件化接入：静态审阅与数值审计分阶段准备材料，审阅依据与变量映射合并维护，兼容已有项目布局。
- 模块复用：知识卡各自维护局部检查器，项目适配器实现变量映射、耦合关系与完整模型检查。
- 按需加载：先检索知识卡元数据，再验证选定卡片；支持局部公式测试缓存，默认重放已有数值结果。
- 知识积累：9张知识卡覆盖功率平衡、储能、机组启停及移动资源，支持提炼、去重、验证和版本归档。
- 运行采集：`collect`记录真实退出状态、耗时、标准输出和依赖快照，生成待审验收记录；MATLAB提供数组观察及UTF-8/JSON导出辅助。
- 项目文档：报告与Feature优化版海报统一四项功能、六步工作流、ReLoop机制比较和修复指标。

## 验证

发布前重新运行131项Python工具与兼容性回归、9张知识卡的45项局部公式测试，均通过。MATLAB六组通用内核与三组独立课程适配器检查通过，新增求解0次；包清单、文件哈希和内部文档链接检查通过。详细记录见[发布核验](../PUBLICATION.md)的v1.1发布封装节。

报告中的效果数据来自v0.15版定向实验；C组最终修复结果包含三项追加复跑，详情列于报告表下注释。1.1版的模型效果对照实验尚未开展。
