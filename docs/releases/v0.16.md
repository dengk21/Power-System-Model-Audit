# PowerSystemModelAudit v0.16

本版将可持续知识学习与项目执行适配器分离，提供可单独安装的轻量Skill。

## 下载与安装

- `power-system-model-audit-v0.16.zip`：仅含Skill。解压后将`power-system-model-audit/`放入客户端的技能目录；Codex个人目录通常为`~/.codex/skills/`。已有同名版本时先备份本地新增知识，再更新并重新加载技能。
- `PowerSystemModelAudit-v0.16-source.zip`：完整仓库，包含通用工具测试、独立课程适配器和文档。需要开发或复现实例时使用。
- `SHA256SUMS.txt`：下载包的SHA-256校验值。

安装包不附课程原始数据、历史求解结果、MATLAB或第三方求解器。Python知识与项目管理工具只使用标准库，建议Python 3.10或更新版本；MATLAB数值检查及真实求解需配置对应环境。Skill安装后不会自动训练模型或执行求解。

## 主要变化

- 新增约束知识学习、检索、来源变化复核和版本归档；提供8张约束卡片及40项局部公式fixture。
- 普通审计识别经典结构并自动学习；非经典、混合或不确定结构默认询问学习偏好。持久偏好只保存在本机。
- Skill只保存可复用知识、规范、通用工具和空白模板。项目适配器、数学规范、映射、测试、运行结果与日志留在项目中。
- 新增项目适配器`init/status/freeze`：首次接入生成并核验，依赖未变则复用，变化后复核并版本化。初始化仅创建未实现骨架，完整数学适配仍由Agent完成。
- 同时输出极简行动简报和完整专业报告。

## 迁移说明

原Skill内`examples/`及固定课程入口`psaudit_run`已迁到仓库`projects/course-audit/`。只安装Skill不会安装课程适配器；旧课程使用者需分别添加Skill通用脚本及独立课程适配器路径。新项目生成自己的入口，不扩展旧课程caseId。

知识来源缺失、来源变化或条件不匹配时保持待复核状态；`FRESH`仅表示声明依赖未变。局部fixture通过不代表完整模型正确，`COMPLETED`也不表示模型没有错误。
