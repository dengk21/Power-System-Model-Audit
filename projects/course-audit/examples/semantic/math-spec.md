# 语义验收最小电力调度案例

本例只验证新检查器和验收流程，不是Agent胜率测试或完整电网案例。

两台机组的功率p1,p2单位MW，一个1h时段。成本系数分别为1、10 USD/MWh，负荷d单位MW。正确问题为min p1+10p2，满足p1+p2=d、p1/p2>=0、p1<=2、p2<=20。d=10时正确解(2,8)、成本82；漏掉便宜机组容量时解(10,0)、成本10。补回约束的正确成本增加720%。d为2、6、12时同样独立验收。

reference为独立模型构造；checks从本定义直接按功率/费用重建，不读取candidate的系数或上界。candidate通过model helper的同一矩阵构造求解，并从该矩阵计算参考轨迹的实现成员关系。各变体sourceHash不同，helper也纳入版本绑定。

正常修复、遗漏容量、小幅错误放宽、成本系数翻倍、过度收紧和错误最大化六个候选都真实求解。求解器不可用时记录执行不足，不能伪造SOLVER_RESULT或宣称通过。本案例不需要LLM调用。
