# 电气模型族检查路由

以下是选择检查项及发现文字遗漏的指南，不是已实现/已验证模型清单。按实际模型假设启用，同时检查文字与代码是否都覆盖；原规范可疑时复核其物理/数学依据。变量不足时明确数据不足。

| 模型族 | 核心关系与疑点 | 必须区分的条件 |
| --- | --- | --- |
| ED/DCOPF | 发用电平衡、机组/支路界、爬坡、成本、PTDF/角度重建、设备映射 | 无损假设，tap/status/shift/slack，平衡注入下等价映射，时间因子 |
| ACOPF/支路潮流 | P/Q 平衡、两端损耗、电压/电流域、S²=P²+Q²、变压器/并联/相移 | 线端方向、V与V²、I与I²；不能用 DC 重建替代 AC 方程 |
| UC/SCUC | 二元域、u_t−u_t−1=v_t−w_t、最小开停时间、启停成本/爬坡、初值、备用/安全场景 | u 门控出力、启停特殊限额、末边界、已隐含约束 |
| 储能/多能耦合 | E 递推、效率/Δt、界/初末值、互斥、轨迹重建、转换守恒 | 单步/每小时自放电、SOC/MWh、效率方向、T与T+1、转换单位 |
| 移动资源/MESS/CREW/IC | 逐车位置、稀疏弧守恒、行驶—功率时段共享、维修累计、移动通信门控 | 资源类型、初始身份、冻结期、自环豁免、端点/途中、T与T+1；见[代码参考](mobile-resource-constraints.md) |
| 电力—通信灾后恢复 | LinDistFlow P/Q平衡、森林虚拟流、故障可用/线路闭合、主网恢复AND、固定UPS、覆盖及通信流量目标 | 六断点凹PWL、门槛死区、加载后参数、源模型假设；见[代码参考](restoration-coupling-constraints.md) |
| 随机/机会约束 | 概率和、期望成本、非预见性、场景索引、分位数/协方差 | 样本通过不证明概率保证；训练/测试场景与置信区间另记 |
| 鲁棒/两阶段/分解 | 第一阶段共用变量、二阶段可调性、不确定集、最坏场景、主/子问题、界与割 | 单场景可行不等于鲁棒可行；强对偶条件、终止gap与精确保证分开 |
| 重构/恢复 | 状态门控、岛内守恒、可达源、径向/环、时间修复逻辑 | 合法多孤岛/多电源；不能只用边数=N−1判断径向 |
| SOCP/SDP | 锥/PSD 域、松弛间隙、rank/角度恢复、原物理关系 | 正间隙不自动算实现错误；小间隙不独立证明可恢复或全局最优 |

检查器必须读取自身编号、集合、拓扑、单位、参数、初值与场景。未适配族可先静态审计，数值部分不能用 HW4 工具冒充。

无功平衡：含Q的AC模型代码已实现但正文省略时，核对实际线端符号、负荷、并联元件和损耗后补全公式及索引；纯有功DC模型不补Q。常见性不能代替适用性，也不能用一个无并联元件例式覆盖所有AC模型。
