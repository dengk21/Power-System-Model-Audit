# 无损DC节点有功平衡

## 数学形式

支路—节点关联矩阵A的起点为+1、终点为-1，支路F按该方向计量时：

$$P^{gen}_{i,t}-P^{load}_{i,t}=\sum_\ell A_{\ell i}F_{\ell,t},\quad\forall i,t.$$

节点发电应由独立的机组—节点映射聚合。储能、可再生能源、可控负荷及削负荷须在实际系统边界中明确纳入净注入，不能默认为已包含。所有项需统一功率基准和单位。

## 适用条件与边界

无损有功网络、明确的有向支路与节点ID映射。逐节点逐时段验算，不能只比较全网总和。AC损耗、无功平衡或两端功率不相反的支路需另立关系，不能套用单一有向F。该关系不单独证明线路潮流满足DC相角方程或容量限额。

## 常见陷阱

两个节点的负荷错配可以互相抵消，全网总平衡仍通过；支路方向、母线编号与数组行号也不可混用。若F由同一净注入重新计算而来，KCL只能说明重建一致；验证被审模型自身还需实际F/相角及源码约束映射，缺项保持数据不足。

## 独立依据与验证范围

节点稳态有功守恒与有向关联矩阵定义。两节点中发电100、负荷20/80、支路80应通过；将负荷改为10/90仍保持总负荷100，但两节点各偏差10，应被逐节点检查检出。反向支路与反向功率属于等价表示。仅LOCAL_TESTED，未新增完整求解案例。
